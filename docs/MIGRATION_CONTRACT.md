# SoundField Tauri 이식 계약

## 목표

기존 PyQt6 SoundField의 기능, 동작, 레이아웃, 상태 전이, 예외 처리를 1:1로 유지한다.
Tauri 버전에서 바꾸는 것은 시각 표현 계층뿐이다.

## 기준

- 유일한 동작 명세는 `C:\Users\samter96\Desktop\Sound_Search_program`의 현재 코드다.
- 기존 화면의 패널 위치, 크기 비율, 정렬, 표시 조건, 반응형 기준은 기능으로 취급한다.
- 키보드, 마우스, 휠, 드래그, 포커스, 지연 시간, 임계값, 툴팁과 문구를 보존한다.
- 임의의 레이아웃 개선, 컨트롤 이동, 동작 단순화, 영어 문구 추가를 금지한다.
- PoC 디자인은 색, 표면, 테두리, 아이콘, HiDPI 표현에만 사용한다.

## 완료 조건

한 영역은 다음 네 조건을 모두 만족해야 완료다.

1. 원본 코드의 관련 이벤트와 상태를 전부 목록화했다.
2. Tauri 구현이 같은 입력에 같은 상태 전이를 만든다.
3. 원본과 Tauri를 같은 창 크기에서 시각 비교했다.
4. 키보드와 마우스 시나리오를 실제 실행 창에서 검증했다.

백엔드가 더미이거나 클릭만 가능한 시각 껍데기는 완료로 기록하지 않는다.
