# SoundField Tauri 이식 검증표

상태 표기: `미착수`, `추출 중`, `UI 부분`, `동작 부분`, `실행 검증`, `완료`.
`완료`는 `MIGRATION_CONTRACT.md`의 네 조건을 모두 만족할 때만 사용한다.

## 감사 기준선

- 원본 UI 파일: 18개, 약 20,000줄
- 원본 UI의 키보드/마우스/드래그/포커스 이벤트 처리 지점: 최소 232개
- 크기/여백/툴팁/체크/포커스 관련 선언: 최소 341개
- 시그널 및 연결 지점: 최소 574개
- 원본 저장소는 읽기 전용으로 취급한다.

- 빈 자식 행 Backspace는 행을 지우고 이전 입력 끝으로 포커스를 옮긴다.

- Space는 선택 결과를 재생/일시정지하며 목록을 스크롤하지 않는다.
- H는 히스토리를 열고 닫으며 Ctrl+P는 환경설정을 열고 닫는다.

### 2026-08-31 결과표 정책 복원 3차

- 원본 `results_table.py`의 컬럼 정의 14개를 확인했다: `파일명`, `PATH`, `길이`, `SR`, `CH`, `BIT DEPTH`, `코덱`, `크기`, `제목`, `아티스트`, `앨범`, `장르`, `코멘트`, `비트레이트`.
- 기본 표시 컬럼은 원본처럼 7개만 켠다: `파일명`, `길이`, `SR`, `CH`, `BIT DEPTH`, `코덱`, `PATH`.
- 원본 코드가 `duration`을 visual index 0으로 옮기는 정책을 확인하고, Tauri 기본 표시 순서를 `길이 → 파일명 → PATH → SR → CH → BIT DEPTH → 코덱`으로 맞췄다.
- `파일명` 컬럼은 잠금 처리해 숨길 수 없게 했다. 다른 컬럼은 헤더 우클릭 메뉴에서 켜고 끌 수 있고, 최소 1개 컬럼은 남긴다.
- 컬럼 폭/순서/표시 상태는 사용자가 바꾼 상태를 `localStorage`에 저장하고 복원한다. 원본의 `~/.soundfield_config.json` 호환 저장은 아직 미착수다.
- 결과표는 앱 시작 직후 임의 정렬하지 않는다. 헤더 클릭 이후에만 수동 정렬 상태를 가진다.
- 숫자 컬럼 정렬 키는 문자열이 아니라 숫자로 분리했다: 길이, SR, CH, BIT DEPTH, 크기, 비트레이트.
- SR 표기는 사용자가 지적한 실제 화면 기준으로 `44100hz` 형식을 유지했다.
- 결과 행은 HTML 기본 파일 드래그를 쓰지 않는다. 원본 DAW 드래그 정책과 충돌하므로 실제 OS 파일 드래그/긴 경로 임시 복사/드롭 완료 정지 정책을 붙일 때까지 비워둔다.
- 단일 클릭은 선택만 변경하고 더미 재생을 시작하지 않는다. 더블클릭은 명시 재생으로 남겼다.
- 선택 활성화는 원본처럼 즉시 재생이 아니라 35ms 지연 콜백으로 분리했다.
- 행 우클릭은 현재 선택을 바꾸지 않고, 클릭한 행이 선택 밖이면 그 행 1개 기준, 선택 안이면 현재 다중 선택 기준으로 메뉴 문구를 만든다.
- 결과 행 컨텍스트 메뉴 문구를 원본 기준으로 맞췄다: `이 라이브러리 파일 브라우저에서 보기`, `탐색기에서 보기`, `이 파일 이름 복사`, `경로 복사`, `이 사운드 블랙리스트에 추가`, `이 라이브러리 블랙리스트에 추가`.
- Tauri/WebView 기본 브라우저 우클릭 메뉴를 전역 차단했다. 원본 앱에는 `뒤로/새로 고침/검사` 같은 메뉴가 없어야 한다.
- 실행 검증: `npm run build` 통과, Tauri 실행 창에서 헤더 우클릭 컬럼 메뉴 14개 표시, 기본 7개 체크, SR `44100hz`, 결과 행 우클릭의 블랙리스트 메뉴 문구, 브라우저 기본 메뉴 차단을 확인했다.
- 미검증/미착수: Ctrl/Shift 다중선택의 물리 입력 자동검증, 650ms 지연 툴팁, 실제 탐색기 열기, 실제 블랙리스트 DB 반영, DAW 파일 드래그 아웃.
- 추가 보정: 헤더 우클릭 컬럼 메뉴는 사용자 드래그 후의 현재 시각 순서가 아니라 원본 컬럼 정의 순서 14개를 기준으로 표시하도록 맞췄다.

**파형 빈 상태 문구** — PoC 가 임의로 넣은 `결과 목록에서 파일을 클릭하면 파형이 표시됩니다` 를

| 조건 | 원본 문구 |
|---|---|
| 파일 없음 | `선택된 파일 없음` |

**목록 지연 툴팁 (원본 `_DENSE_LIST_TOOLTIP_DELAY_MS = 650`)**

- 브라우저 기본 `title` 툴팁은 지연 시간과 모양을 제어할 수 없어 직접 구현했다.

- **좌버튼을 누른 채 이동(드래그 의도)이면 띄우지 않는다** (`event.buttons !== 0` 가드) — 원본과 동일.
- 스크롤/휠/마우스다운/이탈 시 즉시 취소. 언마운트 시 타이머 정리.

#### 4) 파일 브라우저 옆 `+` 버튼이 작동하지 않음

핸들러가 아예 없었고 툴팁도 `폴더 추가` 로 잘못돼 있었다.

### 환경설정 창을 원본 구조로 재작성

PoC 의 설정 창은 원본에 없는 항목(글자 크기 3단 등)을 담고 있었다.
원본 `SettingsDialog` 를 그대로 옮겼다.

- 창 제목 `환경설정`, 탭 6개: **일반 / 테마 / 재생 / 인덱싱 / 중복 검수 / 단축키**
- 하단 `[기본값으로 초기화] [저장] [취소]`
- **일반**: 검색 최대 노출 개수(100~5000, 기본 500) + 원본 hint 전문 /
  결과 목록 동작 `원클릭으로 재생`·`더블클릭으로 재생`(기본 원클릭) /
  결과 텍스트 크기 `보통 (기본)`·`작게 (한 화면에 더 많이)` — **2택**이다. 3단이 아니다
- **테마**: `뉴트럴 (기본)` / `라이트` / `네온` + `저장 버튼을 누르면 적용됩니다.`
  → 라디오 선택만으로 즉시 적용하지 않는다. **저장에서만 반영**한다 (원본 동작)
- **재생**: 정지 후 재생 방식 2택(기본 처음부터) / `결과 선택 시 즉시 재생 (자동 미리보기)`(기본 꺼짐)
  / `DAW 로 드래그 시작 시 재생 정지`(기본 켜짐) + 원본 툴팁 전문
- **인덱싱**: 즉시 / Idle 2택 + Idle 정책 설명 전문
- **단축키**: 6종(Space/Home/R/S/H/Ctrl+P) 편집 + 휠 단축키 3종은 원본처럼 회색 비활성
  (`Ctrl+휠`, `Ctrl+Alt+휠`, `Shift+휠`, 툴팁 `이 단축키는 변경할 수 없습니다`)
- `기본값으로 초기화` 는 원본 `_on_reset` 처럼 **테마 라디오는 건드리지 않는다**

`결과 텍스트 크기`는 실제로 연결했다 — 원본 `set_config` 의 `compact_results` 대로
행 높이 30px → **22px**, 셀/배지 폰트 축소. `localStorage` 에 저장한다.

### 죽은 버튼 전수 조사 후 연결

정규식으로 `onClick` 없는 `<button>` 을 전부 뽑아 확인했다. 이번에 연결한 것:

- 파일 브라우저 `+` (새 탭) — 위 4번
- 라이브러리 검색 결과 목록 **드랍다운 접기/펼치기** (원본 토글)
- 블랙리스트 항목 **제거** (로컬 상태 — 실제 DB 반영은 백엔드 연결 후)
- 히스토리 **지우기** + 개수 갱신 (로컬 상태)
- 환경설정 안 모든 컨트롤 (탭/라디오/체크/단축키/중복 검수 트리 펼침)

**아직 눌러도 반응이 없는 것 (백엔드 필요, 의도적)**:
`빠른 갱신` / `전체 갱신` / `취소` / 중복 검수의 `중복 검수 시작`·`검색 제외`·`제외 관리` /
트리 우클릭 메뉴의 재스캔·제거·이름변경 / 결과 우클릭의 탐색기 열기·블랙리스트 추가.
이들은 인덱싱·DB·파일 시스템 작업이라 가짜로 동작시키지 않았다. 중복 검수 버튼들은
비활성 + 툴팁으로 이유를 표시했다.
