### 2.4 슬라이더 동작 규칙

- **우클릭 = 기본값 리셋**, **Ctrl+좌클릭 = 리셋** (`_ResetSlider`) `[432]`
- 슬라이더는 `NoFocus` — Qt 기본 점선 포커스 테두리가 슬라이더 외곽선처럼 보이는 것 방지
- 속도: 휠 1틱 = 1스텝 (`_SingleStepSlider`), 볼륨: 휠 1틱 = **0.25 dB** (`_VolWheelSlider`)
- 값 라벨 **더블클릭 → 인플레이스 입력창**. Enter/포커스아웃 = 확정, **Esc = 취소** `[465]`

### 2.5 속도 · 볼륨 매핑

**속도** `[3220]`: 슬라이더 `-100 ~ +100`, `rate = 2^(p/100)`.
→ p=0 이 정확히 1.0x 중앙, 양끝 0.5x / 2.0x 대칭. (선형이면 1.0x가 1/3 지점이라 왼쪽 치우침)

**볼륨** `[2797]` — DAW식 로그 테이퍼:
```
슬라이더 0 ~ 1000,  VOL_UNITY_POS = 750 (0.00 dB, 리셋 기본값)
VOL_MAX_DB   = +6.02 dB (pos 1000, 게인 2.0)
VOL_FLOOR_DB = -50.0 dB (pos 1), pos 0 = -∞ (음소거)
부스트 구간(750~1000)과 컷 구간(1~750) 각각 dB 선형
```
0 dB 가 **75% 위치** — 상단 25%만 부스트. 해상도 1000 은 휠 0.25dB 단위를 위해.

### 3.3 파형 색 (테마별) `[2570]`

| 테마 | 채움색 | 가장자리 alpha |
|---|---|---|
| light | `rgb(70,64,47)` | 95 |
| grey | `rgb(240,240,240)` | **160** (대비 강화) |
| dark | `rgb(120,175,245)` | 95 |

**채널별 세로 그라데이션** — 중앙(0선)이 진하고 가장자리로 갈수록 옅어진다.
grey 테마만 알파 변주 대신 **실제 RGB 대비**를 쓴다 `[2612]`:
```
0.00 → rgb(58,61,68)     0.30 → rgb(120,124,132)
0.50 → rgb(249,250,252)  0.70 → rgb(120,124,132)   1.00 → rgb(58,61,68)
```
0.30/0.70 중간 스톱으로 중앙 falloff 를 가파르게 → 얇은 파형도 그라데이션이 또렷.

**재생/미재생 색 분리는 쓰지 않는다** — 매 프레임 clip + 폴리곤 2회가 비싸서 단일 색으로 단순화(사용자 결정) `[2519]`

채널 구분선: `rgba(255,255,255,32)` 1px `[2634]`

### 3.9 줌 · 팬 `[2011]`

| 조작 | 동작 |
|---|---|
| `Ctrl + 휠` | 가로 줌 — **마우스 커서 위치 고정(앵커)**, 1.5배/틱 |
| `Ctrl + Alt + 휠` | 세로(진폭) 줌 — 1.5배/틱, 최대 **8배** |
| `Shift + 휠` | 가로 스크롤 — 줌인 상태에서만, viewport의 **10%/틱** |

- 범위: `MIN_ZOOM 1.0`, `MAX_ZOOM 1000.0`, `ZOOM_STEP 1.5`, `MIN_AMP 1.0`, `MAX_AMP 80.0`
- 애니메이션: **목표값만 바꾸고 현재값을 보간**. 줌은 **log-space lerp**(1.5배 단계가 같은 속도로 보임), viewport는 선형. `ZOOM_ANIM_T = 0.4초`
- 줌 애니메이션 중에는 **AA 끄고 2픽셀 step** (성능), 정지 시 AA 켜고 1픽셀
- **파일 전환 시 줌 기억하지 않는다** — 항상 전체 보기로 리셋. (이전 파일 줌이 길이가 다른 새 파일에 적용돼 "뒷부분 잘려 보이던" 문제 때문) `[1976]`

### 3.12 성능 구조 `[2514]`

### 4.5 드래그 아웃 `[1263]`

`setDragEnabled(True)`, `DragDropMode.DragOnly`

**시작 조건** — 전부 만족해야 시작:
1. 좌버튼이 눌린 채 이동
2. **누른 행을 벗어남** (`_within_press_row` 가 False) — 행 안에서의 이동은 클릭/오디션으로 보고 드래그하지 않는다
3. 이미 드래그 중이 아님 (`_dragging`)
4. 좌버튼이 **우리 위젯 안에서** 눌렸음 (`_left_pressed`)
5. **OS 실시간 버튼 상태**가 눌림 (`GetAsyncKeyState(VK_LBUTTON)`) — Qt 의 `mouseButtons()` 는 캐시된 값이라, 이미 뗐는데 release 이벤트가 큐에 남아 있으면 드래그가 시작돼 라벨이 커서에 붙는 버그가 난다 `[33]`

**좌버튼이 눌린 채의 이동은 base class 로 절대 전달하지 않는다** — Qt 내장 드래그(행 이미지 pixmap + 비-파일 MIME)와 러버밴드 선택을 원천 차단.

MIME: `setUrls([파일 URL...])` (다중 선택 시 전부)

**드래그 커서**: `IgnoreAction` 에 1×1 투명 pixmap 을 지정 → OS 기본 "drop OK" 커서로 fallback → 툴 내부를 지날 때 금지 표시가 뜨지 않는다 `[1288]`

**드래그 라벨 pixmap** `[1331]`:
- 파일명 (여러 개면 `이름  +N`)
- 배경 `rgba(0,0,0,200)`, radius 4, 글자 흰색
- 폭 = `텍스트폭 + 24` (최대 480), 높이 = `글자높이 + 12`, 좌패딩 12
- hotspot `(12, 높이/2)`

**긴 경로 처리** `[290]`: Windows MAX_PATH(**256자**) 초과 파일은 탐색기/누엔도가 열지 못하므로,
`%TEMP%\SoundField_longpath` 에 **원본이름 + 해시8자 + 확장자**로 복사해 그 경로를 드래그한다.
해시를 뒤에 붙여 앞부분이 원본과 같게 → 이름으로 재검색 가능.
